# 🏝️ Beach Chill Map — สคริปต์สร้างแม็พเกาะนั่งชิลล์ (Roblox)

สคริปต์ไฟล์เดียว `BeachChillMap.server.lua` สร้างแม็พทั้งเกาะให้อัตโนมัติ

## วิธีติดตั้ง

**แบบ A — ง่ายที่สุด**
1. Roblox Studio → `ServerScriptService` → Insert **Script**
2. ลบโค้ดเดิมออก แล้ววางโค้ดทั้งไฟล์ลงไป
3. กด **Play** แม็พจะสร้างประมาณ 5–20 วินาที ผู้เล่นจะเกิดหลังสร้างเสร็จ

**แบบ B — สร้างแม็พลงไฟล์ถาวร (เปิด Studio แล้วเห็น/แก้ต่อได้เลย)**
1. View → **Command Bar** แล้ววางโค้ดทั้งไฟล์ กด Enter
2. ใส่สคริปต์เดียวกันไว้ใน ServerScriptService ด้วย (ตอน Play จะเห็นว่ามีแม็พแล้ว จึงรันแค่แอนิเมชัน)

> ⚠️ ค่าเริ่มต้นจะ **ล้าง Terrain เดิมทั้งหมด** (`CLEAR_TERRAIN = true`) ควรบันทึกไฟล์สำรองก่อน
> โมเดล Part เก่าใน Workspace (บ้าน ต้นไม้เดิม) จะไม่ถูกลบ ต้องลบเองถ้าซ้อนกัน

## มีอะไรในแม็พ

| ส่วน | รายละเอียด |
|---|---|
| ภูมิประเทศ | เกาะรูปทรงธรรมชาติ (noise) เนินหญ้า ตลิ่ง หาดทรายมีลอนคลื่น น้ำตื้นสีฟ้าใส แล้วค่อยลึกลง หน้าผาหินและกองหินกลางทะเล ทางเดินดินโค้งพร้อมหินวางเป็นขั้น หญ้า 3D |
| ต้นมะพร้าว | ลำต้นโค้งแบบ Bezier เรียวลง มีวงรอยกาบใบ โคนบาน ใบแต่ละทางมีก้านโค้งย้อยและใบย่อยรายใบ มีใบแห้ง ลูกมะพร้าว |
| บาร์ริมหาด | บ้านใต้ถุนสูง พื้นไม้ทีละแผ่น ผนังไม้ไผ่ เคาน์เตอร์ เก้าอี้บาร์ ชั้นขวด หลังคาจากซ้อนชั้นพร้อมชายจากห้อย ป้าย "CHILL BAR" ไฟประดับ โคมไฟ เซิร์ฟบอร์ด |
| โซนอาบแดด | ร่ม 3 คัน (ผ้าแบ่งเป็นกลีบ มีโครงและชายระบาย) เตียงไม้ 6 ตัว มีเบาะ หมอน ผ้าขนหนู โต๊ะข้างพร้อมค็อกเทล มะพร้าว แว่นกันแดด |
| ท่าเรือ | แผ่นไม้ทีละแผ่น เสาที่มีคราบตะไคร่ตรงระดับน้ำ ราวเชือกหย่อน โคมไฟ ม้านั่งหันออกทะเล บันไดลงน้ำ ห่วงชูชีพ เรือพายที่โยกตามคลื่น |
| กองไฟ | วงหิน ฟืน ถ่านแดง ไฟพร้อมควัน แสงไฟกระพริบ ม้านั่งท่อนซุง คบเพลิงรอบวง |
| อื่น ๆ | เปลญวนระหว่างต้นมะพร้าว ผ้าปูชายหาด กระติกน้ำแข็ง ลูกบอล ปราสาททราย เปลือกหอย ปลาดาว ขอนไม้ลอยน้ำ พุ่มไม้ดอก เฟิร์น นกนางนวลบินวน |
| แสง/บรรยากาศ | เวลาแดดเย็นสีทอง, Future lighting, Atmosphere, เมฆ, Bloom, SunRays, Color Correction, Depth of Field, ปรับสีน้ำทะเลกับสีวัสดุ Terrain |

นั่งได้ (Seat) ที่เตียงอาบแดด เปลญวน ม้านั่งท่อนซุง เก้าอี้บาร์ และม้านั่งท้ายท่าเรือ

## ตั้งค่า (ส่วน `CONFIG` บนสุดของไฟล์)

- `QUALITY` — `"Mobile"` / `"Balanced"` / `"High"` (ถ้าเล่นบน iPad/มือถือแล้วกระตุก ให้ใช้ `"Mobile"`)
- `SEED` — เปลี่ยนเลขเพื่อสุ่มรูปเกาะและตำแหน่งต้นไม้ใหม่
- `TIME_OF_DAY` — เช่น `14` = กลางวันจ้า, `17.6` = พระอาทิตย์ตก
- `DAY_CYCLE` — `true` ให้เวลาเดินเอง
- `SOUNDS` — ใส่ ID เสียงคลื่น/นก/เพลงจาก Creator Store (ค่าเริ่มต้นเว้นว่างไว้ จึงยังไม่มีเสียง)

## ข้อจำกัด

- ใช้แค่ Part และวัสดุที่มีใน Roblox ไม่มี Mesh หรือ Texture จากภายนอก จึงยังดูไม่สมจริงเท่าโมเดลที่ทำจาก Blender ถ้าต้องการให้สมจริงขึ้นอีก ให้เปลี่ยนต้นมะพร้าวหรือร่มเป็น MeshPart จาก Creator Store แล้วใช้ตำแหน่งเดิมได้
- ยังไม่ได้ทดสอบใน Roblox Studio จริง (ตรวจได้แค่ว่าโค้ด compile ผ่าน) ถ้ามี error ใน Output ให้ส่งข้อความมาได้เลย
