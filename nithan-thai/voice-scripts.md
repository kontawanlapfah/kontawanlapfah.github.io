# บทพูดสำหรับอัดเสียง — NithanTH · Putri di Thailand ตอน 1–3

## วิธีใช้
- อัด **1 ประโยค = 1 ไฟล์** ตั้งชื่อไฟล์ตามคอลัมน์ "ชื่อไฟล์" (เช่น `ep01_02.mp3`) แล้วส่งมาในแชต
- **ความยาวไม่ควรเกินช่อง "เวลาสูงสุด"** (ถ้ายาวกว่านี้นิดหน่อยไม่เป็นไร ผมจะปรับจังหวะภาพให้)
- ตัดความเงียบหัว-ท้ายไฟล์ออก
- ⭐ = แนะนำให้ **อัดเสียงเอง** (ต้องการวรรณยุกต์ที่ "ผิดแบบตั้งใจ" หรือการออกเสียงไทยที่แม่น)
- บรรทัดที่ไม่มี ⭐ ใช้ ElevenLabs ได้

## เสียงตัวละคร (ตั้งใน ElevenLabs)
| ตัวละคร | ลักษณะเสียง | ภาษา |
|---|---|---|
| **ปุตรี (คิดในใจ)** | ผู้หญิงอายุ ~20 ปี สดใส ขี้ตกใจ | อินโด |
| **ปุตรี (พูดไทย)** | เสียงเดียวกัน แต่พูดไทย **สำเนียงต่างชาติ** ช้าๆ ไม่มั่นใจ | ไทย |
| **ป้า (Bibi)** | ผู้หญิงวัย 50+ ใจดี เป็นกันเอง | ไทย |
| **ต้น (Ton)** | ผู้ชายวัยมหาลัย สุภาพ ร่าเริง | ไทย |
| **พี่ฟ้า (Fah)** | ผู้หญิงวัย 20+ ขี้เล่น | ไทย |
