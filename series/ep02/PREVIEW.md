# EP02 ขนมปังจากค่ายของเขา: พรีวิว

ที่มา: เอกสารซีรีส์ ตอนที่ 2 · รูปแบบเดียวกับ EP01 (9:16, โลโก้มุมขวาบน, ป๊อปอัพโลโก้ปิดท้าย)
ความยาวพรีวิว 2:04 (ยังไม่มีเสียงพากย์ พอได้ไฟล์เสียงจะปรับจังหวะภาพตามเสียงเหมือน EP01)

## หลักที่ใช้
- บทบนจอทุกบรรทัดตรงตามเอกสาร (Hook, สคริปต์, Cliffhanger, CTA)
- ช็อตตาม "แนวทางภาพประกอบ" ตอนที่ 2 ข้อ 1–5
- ไม่มีภาพนบี ไม่มีใบหน้าดัจญาล; ชัยค์ยะห์ยาถ่ายจากด้านหลังตามที่เอกสารกำหนด
- คำพูดของชัยค์ยะห์ยาที่อ้างท่านนบี ﷺ มีป้ายเล็กกำกับว่า "ถ่ายทอดความหมายจากหะดีษ · สุนันอบีดาวูด 4319" เพราะเอกสารระบุว่าเป็นการถ่ายทอดความหมาย ไม่ใช่ถ้อยคำตรงตัว
- คำเตือนท้ายคลิป + หลักฐานหลักตามตารางรายชื่อตอน: สุนันอบีดาวูด 4319, เศาะฮีห์มุสลิม 588

## ส่วนที่ผมตีความเพิ่ม (ไม่มีในเอกสาร ตัดออกได้)
1. ป้ายแหล่งหะดีษเหนือคำบรรยาย 2 จุด (อบูดาวูด 4319 / มุสลิม 809 · 588)
2. จุด 10 จุด สว่าง 5 จุด (ต่อเนื่องจาก EP01)
3. ฉากภายนอกมัสยิดก่อนเข้าไปข้างใน และนกบินยามเช้า
4. ฮาวาเดินมาข้างหลัง แล้วอาดัมคุกเข่ากอด (สคริปต์บอกแค่ "กอดไว้แน่น")
5. นาฬิกาตอนเช้าเริ่มที่ 5:30 แล้วเดินไปถึง 14:30 (เก้าชั่วโมงตามบท; เวลาเริ่มเป็นการสมมติ)

## ภาษา (ตรวจทุกบรรทัดบนจอ)
- ทุกบรรทัดตรงกับเอกสาร ไม่มีคำผิด และไม่มีคำขาดกลางบรรทัด
- แก้ 3 จุด: "ตาของเพื่อนผม…" → "แววตาของเพื่อนผม…"; CTA "กดติดตามกับแชร์ไว้" → "กดติดตามและแชร์ไว้"; ป้ายหลักฐานย่อเป็น "เศาะฮีห์มุสลิม 809, 588"
- คงไว้ตามเอกสาร: "ชัยค์ยะห์ยา", "ศุบห์", "ธรณีประตู", และแก้ Hook "…และนั่นคือเสียงที่ทำให้…" → "…และนั่นคือสิ่งที่ทำให้…" ตามที่ตกลง
- ﷺ แสดงด้วยฟอนต์อาหรับ Amiri

## เสียงประกอบ (sound.py, ใช้ชุดเครื่องมือกลาง shared/sfx.py)
ห้องเงียบ → ผ้าขยับตอนฮาวาตื่น → ลมกลางคืน + ตะเกียงปะทุที่ประตู → วางขนมปัง → ประตูลั่นช้า ๆ + กลอนแตะ → ฝีเท้าฮาริสห่างออกไป → ฝีเท้าเล็ก ๆ ของฮาวา → นกยามเช้าที่มัสยิด → ผ้าขยับตอนจับมือ → จิ้งหรีดกลางคืน → นกยามรุ่ง + เข็มนาฬิกา → เข็มนาฬิกาเร่งเร็วตอนไทม์แลปส์ → เหลือเสียงเข็มทีละครั้งตอนดวงอาทิตย์ค้าง → เงียบตอนตัดดำ → ป๊อปเบา ๆ ตอนโลโก้
